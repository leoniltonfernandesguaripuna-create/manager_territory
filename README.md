# 🌍 Territory Manager

Aplicativo Flutter para gerenciamento do território da congregação.

## ✨ Funcionalidades

- **Territórios** — lista de territórios com foto do mapa
- **Grade DIRIGENTE** — controle de quem dirigiu o campo
- **Quadras Trabalhadas** — marcação interativa (1 toque = amarelo, 2 = verde)
- **Serviço de Campo** — agenda mensal com atribuição automática de dirigentes
- **Dirigente** — cadastro de irmãos por dia da semana
- **S.13** — registro de designação integrado com a aba Territórios
- **Eventos** — grade com busca de nomes, dias e pagamento
- **Administrador** — login com 4 perfis (Principal, A, B, C) e permissões

## 🔐 Perfis de acesso

| Perfil | Pode editar |
|---|---|
| **Visitante** | Apenas grades DIRIGENTE e QUADRAS |
| **Admin A/B/C** | Tudo |
| **Admin Principal** | Tudo + cadastra senhas dos admins A, B e C |

**Senha padrão do Admin Principal:** `0000`

## 🚀 Como rodar

git clone https://github.com/seu-usuario/territory_manager.git
cd territory_manager
flutter pub get
